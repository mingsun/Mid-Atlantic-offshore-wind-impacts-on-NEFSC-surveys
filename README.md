Code for Sun et al. (2026)

This repository contains the analysis code associated with:

Sun, M., Braid, K., Blaylock, J., Hennen, D., Truesdell, S., & Chen, Y. (2026).
Addressing Spatiotemporal Data Gaps in Fish Abundance Modelling: Insights From Offshore Wind Impacts in the U.S. Mid-Atlantic.
Diversity and Distributions, 32, e70156.
https://doi.org/10.1111/ddi.70156

Overview

This study evaluates how hypothetical survey preclusion within offshore wind energy areas (WEAs) may affect fish abundance estimation in the U.S. Mid-Atlantic.

The repository contains code for:

Processing survey and spatial data
Creating Full and WEA-precluded survey scenarios
Calculating abundance indices
Fitting GAM, Random Forest, and VAST models
Reconstructing missing survey observations
Evaluating changes in abundance estimates and uncertainty
Producing manuscript figures and supporting analyses
Data

The analyses use NOAA Northeast Fisheries Science Center fishery-independent survey data and BOEM offshore wind spatial data. Raw data may not be included in this repository and should be obtained from the original data providers.

Software

Analyses were conducted primarily in R.
